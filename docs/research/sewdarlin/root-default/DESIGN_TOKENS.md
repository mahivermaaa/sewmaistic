- **Announcement Bar Blue:** `#B0C2D1` (soft slate periwinkle blue)
- **Announcement Bar Text:** `#34444F` (deep slate navy)
- **Primary Text / Heading Slate:** `#4F5A5E` (rgb(79, 90, 94))
- **Body Text:** `#2E3A42` / `#4A5559`
- **Pill Button / Accent Rose:** `#D8A7A7` (hover: `#C89696`, active: `#B88585`)
- **Pill Button Text:** `#FFFFFF` or `#3E484C`
- **Testimonials Section Mauve:** `#D5B3B3`

- **Gingham Check Accent (Hero background):** `#F4D3C6` with `#FFFFFF`

## Typography

### Font Families
- **Editorial / Headings Serif:** `Cormorant Garamond`, serif (weights 400, 500, 600, 700; normal and italic)
- **Script / Calligraphy Overlay:** `Alex Brush` / `Playfair Display`, cursive
- **Body / Primary Sans:** `Sora`, sans-serif (weights 300, 400, 500, 600)
- **Secondary Body / Fallback:** `Inter`, ui-sans-serif, system-ui

### Scale
- **H1 (Hero Heading):** 48px - 60px / line-height 1.15, Cormorant Garamond, tracking normal
- **H2 (Section Headings):** 36px - 44px, Cormorant Garamond, slate `#4F5A5E`
- **H3 (Collection / Card Titles):** 24px - 32px, Cormorant Garamond
- **Body Large / Announcement:** 14px - 15px, letter-spacing 0.05em
- **Product Title:** 15px - 16px, Sora / Sans, weight 400
- **Product Price:** 15px - 16px, Sora / Sans, weight 400, color `#4F5A5E`
- **Uppercase Subtitles:** 12px - 13px, letter-spacing 0.25em, weight 500

## Spacing & Dimensions
- **Max Container Width:** 1440px
- **Announcement Bar Height:** 40px
- **Header Height:** ~120px (logo, search pill, cart button, navigation row)
- **Product Card Image Size:** Square aspect ratio 1:1, object-fit cover
- **Collection Cards:** Square or slightly tall (272px x 274px aspect ratio)
- **Button Border Radius:** Full rounded pill `rounded-full` (9999px)
- **Input Border Radius:** Rounded pill or soft border with bottom stroke

## Elevation & Shadows
- **Polaroid Photos:** Soft drop shadow `0 8px 24px -4px rgba(0,0,0,0.12)`, rotated between -4deg and +3deg
- **Quick View Overlay:** Soft glassmorphic pill or card hover animation
- **Floating Chat Bubble:** `0 4px 20px rgba(0,0,0,0.18)`
