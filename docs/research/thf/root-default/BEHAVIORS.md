# Behaviors & Interactivity Bible - The Hazelnut Factory

## Header / Navigation
- **Scroll Behavior:** Sticky top navigation bar. Initially translucent dark background (`rgba(8,12,18,0.80)`) with `backdrop-filter: blur(22px)` and subtle bottom border (`border-bottom: 1px solid rgba(244,249,255,0.05)`).
- **Logo:** High-contrast logo (`/logo/thf-long.svg`) in inverted white tone.
- **Dropdown Menus:** 
  - "SHOP ALL" button reveals dropdown menu of shop categories.
  - "GIFTING" button reveals dropdown menu of gifting options (Weddings, Corporate, BYOB).
- **Mobile Menu:** Hamburger icon toggles slide-out mobile drawer with all navigation links and contact options.
- **Floating Floating Contact Call Button:** Green circular call button fixed at bottom-left (`background: linear-gradient(135deg, #22c55e, #16a34a)`) with pulsing wobble animation.

## Hero Section & Ticker
- **Ticker Bar:** Marquee scrolling effect with "ARTISANAL SWEETS · PAN-INDIA DELIVERY".
- **Hero Title & Copy:** Editorial serif typography for main headings ("Someone had to reinvent mithai. We did it!"), clean sans-serif for subtext.
- **Visual Media:** High-resolution product showcase hero image / carousel banner with overlay gradients.

## Product Showcase & Category Grid ("THF, The Way You Want It")
- **Category Tabs / Filter Pills:** Interactive tabs (All, Labon®, Baklava, Fusion Mithai, Gift Boxes).
- **Card Hover Effects:** Subtle scale transform (`scale(1.02)`), shadow elevation, and image zoom on hover.
- **Quick Action / CTA Buttons:** Glassmorphic buttons with smooth hover color transitions.

## Build Your Own Box CTA Banner
- **Visual Design:** Dark premium card container with accent border and gold/brown button ("START BUILDING").
- **Hover Interaction:** Button scales slightly with arrow icon transition on hover.

## Registered Trademark Spotlight (Labon®)
- **Layout:** 2-column layout (Text left/right, high-res image right/left).
- **Typography:** Custom badge tag `® REGISTERED TRADEMARK` + serif title "Introducing the Labon®".

## Media Coverage Carousel / Grid
- **Publication Logos:** Forbes, Vogue, Economic Times, etc.
- **Card Layout:** Minimalist press cards with quotes and publication badges.

## Client / Corporate Banner
