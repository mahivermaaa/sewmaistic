# Footer Specification

## Overview
- **Target file:** `src/components/sites/thf/root-default/Footer.tsx`
- **Screenshot:** `docs/design-references/thf/root-default/desktop-1440.png`
- **Interaction model:** Expandable FAQ Accordion + Contact Form UI

## Components
1. **Brand Intro:** "Crafted Fresh, Savoured Always." + Instagram `@thf.india`.
2. **Navigation Columns:** Shop, Policies, Company.
3. **Contact Form UI ("Get in Touch"):**
   - Inputs: Name, Mobile, Email, Message
   - Button: "Send Message" (Non-functional visual UI submission with toast notification state)
4. **FAQ Accordion:**
   - 5 Expandable questions (Can I customise my own gift box?, Do you offer corporate gifting?, Shipping policy, Return policy, Physical stores).
5. **Business Info & Legal:**
   - Customer Care No (+91-7084400400), Email (`info@#.com`)
   - Company name, CIN, GSTIN, FSSAI Number, Registered Address.
6. **Watermark & Copyright:** Faded background logo watermark + copyright info.
