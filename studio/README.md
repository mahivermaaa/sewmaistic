# Sewmaistic product dashboard

1. Create a free project at https://www.sanity.io/manage and copy its Project ID.
2. Put the Project ID in `project.ts`.
3. `npm install`
4. `npx sanity login`
5. `npx sanity deploy`  (gives the client a link like https://sewmaistic.sanity.studio)
6. In sanity.io/manage -> Members, invite the client's email as an **Editor** (not Administrator).
